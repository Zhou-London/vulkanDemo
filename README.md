# Vulkan Demo Lumination Engine.

A simple lumination engine built from Vulkan.

## Deps

- C++ 20 (Heavy use of 20 features)
- Vulkan @latest
- glfw3 @latest
- glm @latest
- Workspace configured for MSVC environment

## Get Started

1. Compile Shaders
```bash
$ glslc shaders/simple.vert -o shaders/simple.vert.spv

$ glslc shaders/simple.frag -o shaders/simple.frag.spv 
```

2. Build the projefct
3. Run
